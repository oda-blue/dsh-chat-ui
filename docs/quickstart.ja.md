# はじめての導入（5 分）

DSH（DeepSeek Harness）の web UI を、ChatGPT のようなチャット画面にするプラグインです。
**設定ファイルを書く必要はありません**。鍵もこのプラグインには含まれないので、自分のものを使います。

## 用意するもの

| 必要なもの | 補足 |
|---|---|
| PC（Windows / macOS / Linux） | スマホからは同じ Wi-Fi 経由で使えます |
| **Node.js 20 以上** | `node --version` で確認 |
| **DSH 本体** | 下の手順 1 |
| **モデルの API キー** | OpenAI 互換 / DeepSeek 公式など、DSH が対応するもの。手順 4 |

## 1. DSH を入れる

```bash
npm install -g @deepseek-ai/dsh
dsh --version
```

バージョンが出れば OK（このプラグインは `0.2.1-rc.5` で動作確認）。

- うまくいかない時: Node のバージョン、npm の権限（管理者権限が必要な環境があります）
- 公式: <https://github.com/deepseek-ai/deepseek-harness>

## 2. このプラグインを入れる

```bash
dsh plugin --profile web add github:oda-blue/dsh-chat-ui
```

- PATH の通った `git` が必要です

- `dsh` が見つからない時は `npx @deepseek-ai/dsh plugin --profile web add github:oda-blue/dsh-chat-ui`
- ネットワークで失敗する時は、リリースの `dsh-chat-ui-0.1.1.tgz` を落として
  `dsh plugin --profile web add ./dsh-chat-ui-0.1.1.tgz`

## 3. 起動して開く

```bash
dsh web
```

表示された URL をブラウザで開きます。初回は DSH の「プレビューについて」が出るので
**「続ける」** を 1 回押します。

**入ったかどうかの見分け方**

- サイドバーの見出しが「**チャット**」で、履歴がフラット（ワークスペースの箱がない）
- ホームの見出しが「**何をお手伝いしましょうか？**」
- 会話画面の右上に**パネルのボタンが無い**
- 入力欄の下が「＋」「🛡」「モデル」だけ（開発者向けの文字が出ていない）
- 過去のチャットを開くと、上の帯が題名と「⋯」の 1 行だけ（タブが無い）。入力欄の下に数字の行が出ない

## 4. モデルの鍵を入れる

**設定 → モデル** でプロバイダーを選び、API キーを保存します。
（このプラグインは鍵を扱いません。人に配る時も鍵は含まれません）

## 5. スマホから使う

PC と**同じ Wi-Fi** につないで、PC 側で入口を起動します。

```bash
# DSH を入れた場所によってパスは変わります（プロファイルの中に入っています）
node <DSH_HOME>/profiles/web/node_modules/dsh-chat-ui/bin/web-entry.mjs --host lan
```

表示される `http://<PC名>.local:8123/` をスマホで開きます。「この端末を登録」が出たら、
入口の画面に出ている **8 桁のパスコード**（`passcode:` の行）を入力します。登録は端末ごとに 1 回だけです。
そのあと**ホーム画面に追加**します。iPhone では「DSH チャット」というアプリとして開きます
（アプリ側でも初回だけパスコードを入れます）。

- URL は**変わらない**ので、ブックマークは 1 本で済みます
- 昔の `:8124` の URL も自動で 8123 に転送されます
- パスコードを知らない端末や、他のサイトのページからは使えません（README の「安全のしくみ」）
- **外部公開はしません**。家の Wi-Fi の中だけで使ってください
- 手順 3 の `dsh web` を動かしたままだと、入口とポートがぶつかります。先に止めてください

## うまくいかない時

| 症状 | 確認すること |
|---|---|
| `dsh: command not found` | `npx @deepseek-ai/dsh ...` で代用。PATH も確認 |
| 見た目が変わらない | **Ctrl+F5**（スーパーリロード）。プラグインは入っています |
| `authentication required` | URL が入口の `:8123` か確認（`:8124` は 8123 への転送、DSH 本体は `127.0.0.1:8125`） |
| 「この端末を登録」が出る | 入口の画面の `passcode:` を入力。分からなければ `$DSH_HOME/dsh-chat-ui/entry-pairing.json` |
| 新しいチャットが別のフォルダに入る | `dsh web` を再起動（作業フォルダは起動時に用意されます）。元の DSH の画面では `chat (dsh-chat-ui)` という名前のワークスペースです |
| スマホから繋がらない | 同じ Wi-Fi か。VPN を切る。Windows ファイアウォールで Node を許可 |
| 会話が始まらない | 設定 → モデル に鍵が入っているか |

## 戻し方

```bash
dsh plugin --profile web remove dsh-chat-ui
```

元の DSH の画面に戻ります（DSH 本体のファイルは触っていません）。
履歴の並びはブラウザごとの設定なので、**表示オプション → グループ化 → ワークスペース** で戻せます。
